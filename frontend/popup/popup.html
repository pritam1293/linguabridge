Which language do you want to read in?

Local model

The backend talks to Ollama on 127.0.0.1:11434. Pull a multilingual model first, for example:

ollama pull qwen2.5:7b

Only messages you click are sent, together with the preceding turns visible in the chat. They go to your local backend and local model. Nothing is stored on a server.
